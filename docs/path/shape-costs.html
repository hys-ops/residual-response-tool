Exact costs for a given block shape

Companion computation for the restricted output models

The question

For one input, how should each block choose between a catalogue and a span description?

How it works

  1. On a fixed partition, each retained catalogue block has a catalogue charge c(B) and a least test-list length h(B). The span choice contributes its required number d(B) of independent coordinates instead.
  2. For the set E of catalogue blocks, add their catalogue charges, then add the Cartesian output size: ΣB∈E c(B) + ΠB∈E h(B) ΠB∉E d(B), with the model’s nonempty conventions.
  3. Minimize over the permitted partitions and choices. For a span, evaluation vectors span its dual, so the minimum number of coordinates needed is its dimension.

What carries forward

This is an exact objective for the specified output rules, not a claim that the minimum can be found quickly or that a general equivalence test must materialize it.
