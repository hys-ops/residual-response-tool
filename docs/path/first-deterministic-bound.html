Earlier result; superseded by the block bound

The question

Can the randomized field-evaluation test for arbitrary FBDDs be made deterministic without enumerating every Boolean input?

How it works

  1. Use the classical multilinear encoding: a pair agrees on Boolean inputs exactly when its difference polynomial is zero.
  2. First fix the variable names whose labels occur too often in the two diagrams. The occurrence budget bounds how many such names there can be.
  3. For the remaining variables apply a bounded-read polynomial identity test to the residual encoding. Optimize the cutoff to give a deterministic bound of poly(N) min{2n, 2O(N/log log N)}.

What carries forward

This first result made the frequency of names visible as the cost to improve. Paper 1 replaces its residual test with a common local hitting list; it does not rely on the earlier bound.
