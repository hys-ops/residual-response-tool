A deterministic subexponential-time equivalence test for free binary decision diagrams

Two free binary decision diagrams can read the same input bits in different orders, even on different paths in one diagram. Can we tell deterministically whether they always give the same answer, without checking every Boolean assignment?

Deterministic equivalence, with a counterexample

For two explicitly supplied FBDDs with N total nodes and n distinct queried variables, the manuscript gives a uniform deterministic algorithm with worst-case bit time

poly(N) · min{2n, 2O(N2/3 log(N+2))}.

When the diagrams differ, it returns a Boolean input on which their outputs disagree. The subexponential bound is in the number of supplied nodes; the diagrams do not need a shared variable order.

The proof in three steps

  1. Compare polynomials. Translate each FBDD into a multilinear polynomial. Checking whether their difference is zero is equivalent to checking equality on every Boolean input.
  2. Build one set of tests for a block. Fix the variables outside a block. If the block has k query occurrences, the remaining polynomial has a short triangular recurrence. The manuscript constructs a common list of O(k²) field points that detects every nonzero recurrence of this form, regardless of the fixed values. One fixed FBDD realizes a family of bilinear forms as the outside values vary, showing that quadratic list length can be necessary.
  3. Combine the tests and recover a Boolean witness. Enumerate Boolean values for heavily repeated variables and take the product of the test lists for the other blocks. A nonzero field evaluation can be turned into a Boolean disagreement one coordinate at a time.

Where the lower bound applies

The matching 2Θ(N2/3 log N) bound concerns the cost of two specified rules that use a common partition across modes and explicitly output a Cartesian product of local tests, with the block-size or grid-scan conditions in the paper. It is not a lower bound on arbitrary FBDD equivalence algorithms. The existence of a deterministic quasipolynomial-time algorithm for the general problem remains open in the manuscript.

What Lean checks

The correctness of the decision procedure and the reconstruction of Boolean counterexamples are verified in Lean 4.19.0. The development also checks the common local test construction, the global candidate-count bound, and local quadratic optimality. The replay includes solve_spec and main_checked. Appendix C maps the manuscript claims to declarations.

The full bit-time accounting and the assembly of the routing and expander graph family for the restricted-model lower bound are supplied as written proofs. They are outside the end-to-end Lean verification.

How this grew out of the earlier work

In the residual-response work, the question was what a computation can still learn from one free block after fixing the rest. For FBDD equivalence the roles change: fix the outside variables, describe the polynomial that remains on the block, and build a set of tests that works across all those descriptions. This is the methodological link; the FBDD proof does not assume the earlier HWB theorems.

What is optimal, and what remains open?

General decision algorithm
The upper bound covers any two explicitly supplied FBDDs, with path-dependent variable orders. It returns a Boolean witness if the outputs differ.
Two explicit block-output rules
Both models fix one partition across the input’s branches, permit catalogue or span tests by block, and must output every tuple of the local test points. The two variants are capped blocks (at most δm distinguished data names per block; count the output) and charged grid scans (no cap; also charge each local grid entry read). An algorithm that avoids materializing the product is not subject to this lower bound.

The unrestricted optimal running time is open. In particular, the manuscript does not rule out a deterministic quasipolynomial algorithm.
