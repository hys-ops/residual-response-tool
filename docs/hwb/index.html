Ordinary hidden weighted bit · Bova’s 2016 question

The optimal compressed SDD size of hidden weighted bit

The ordinary hidden weighted bit function needs quasipolynomial compressed SDD size even on the best variable tree. A lower bound holds for every vtree; one explicit vtree attains the matching upper bound.

Minimum directed wires over all vtrees

2Θ((log₂ n)²) = nΘ(log₂ n)

When the input has Hamming weight k > 0, ordinary HWB returns xk; it returns zero at weight zero. The function itself is fixed, not an expanded variant with new inputs.

Proof and research path

From observable responses to matching bounds

At a vtree split, fix an assignment on the left and ask what Boolean function of the right input remains. In a compressed decision, the left prime is exactly the set of assignments that give its right-side response. This common identity supports both halves of the proof.

  1. Inspiration, not a proof dependency

    Observe only what a block can reveal

    In a separate sensitivity proof, a tournament child affected its surroundings only through its height. Classifying the responses to that height suggested organizing assignments by observable behavior.

  2. Exact compression identity

    Group assignments by their full residual function

    Equal responses can share a subcircuit. Conversely, once a response is fixed, compression forces the corresponding prime to be its exact left fiber.

  3. Upper bound · one vtree

    Share recurring responses on dyadic blocks

    Choose consecutive right blocks of sizes 1, 2, 4, 8, … . Bound the continuing choices at each level and count both response and prime circuits, including sharing.

  4. Lower bound · all vtrees

    Follow nested responses through any tree

    Pattern filters distinguish nested responses on actual HWB inputs. Wide cuts and paths of smaller cuts force enough distinct responses after accounting for shared gates.

  5. Conclusion

    Matching bounds in one wire model

    The lower bound covers all admissible vtrees (including unused padding in the Bova-style model), even though the upper bound uses only the original variables. Some individual vtrees can cost more.

Formal verification

What Lean checks

HWB.Paper.sharp_paper_minimum proves matching bounds for the attained minimum in the formal Bova-style circuit model. The translations preserve the relevant semantics, allowed vtree and shared reachable wires. The broader scoped-graph lower bound also allows auxiliary labels read by a circuit if its output is ordinary HWB for every auxiliary assignment.

The supplied record reports a Lean 4.34.1 replay of 70 local modules and a fresh PaperArcAudit kernel check. Sections 7–8 of the written proof explain the correspondence with Bova’s published syntax. This is not a claim of independent peer review or historical priority.

Related results and sources
